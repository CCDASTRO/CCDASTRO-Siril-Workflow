CCDASTRO Siril Workflow 0.2.0 — development release.

Windows users: download and run **CCDASTRO-Siril-Workflow-0.2.0-Setup.exe**. Close the host application first. This per-user installer also handles future version upgrades. Follow the included INSTALL.md for launch/migration details. A portable ZIP and SHA256SUMS.txt are provided.

Includes Color & Tone masks/sliders/curves, reviewed processing passes, FITS result/report export, a Check for updates button, and installer/uninstall support. Optional native/AI commands still require individual configuration and validation; see README scope. Windows installers are not Authenticode signed.
