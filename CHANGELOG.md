# Changelog

## 0.4.0

- Detect installed GraXpert and SyQon providers; configure custom locations and rescan from the workflow.
- GraXpert background extraction and denoising settings.
- SyQon CLI model discovery, declared domains, Parallax stages and Axiom stars output handling.
- Cancellable execution, fail-safe candidate review and external-application access checks.

## 0.3.0

- Dedicated BlurXTerminator, NoiseXTerminator and StarXTerminator passes through a licensed RC-Astro CLI.
- Cancellable background processing and explicit candidate acceptance.
- Generated stars export and screen/add recombination after accepting a StarX pass.
- Executable discovery, device control, license/parameter validation and FITS row-order handling.

## 0.2.1
- Enforce UTF-8 documentation in release packages.

- Per-user Windows installer with host-running protection and uninstall support.
- Reusable installer upgrade path and Start menu documentation/download shortcuts.
- User-requested Check for updates button with background GitHub release lookup.
- Portable ZIP and SHA-256 checksums for each release.
- Version-tagged GitHub Actions build/test/release workflow.
- Revised installation and migration instructions.

## 0.1.0

Initial development workflow with reviewed processing passes, Color & Tone masks/sliders/curves, FITS export and reports.
